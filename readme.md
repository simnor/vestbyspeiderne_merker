# Speidermerker - Vestbyspeiderne

En enkel nettside for registrering og oppfølging av fordypningsmerker og programmerker for stifinnere og vandrere i Vestbyspeiderne, med en innebygd aktivitetsbank som hjelper å finne aktiviteter til merkene.
Nettsiden er basert på merkeprogrammet til Norges Speiderforbund og er utviklet som et hjelpemiddel for speidere og foresatte for å få oversikt over progresjon, oppnådde merker og forslag til aktiviteter.

En enkel webapplikasjon for registrering og oppfølging av:
- Fordypningsmerker
- Programmerker

for

- Stifinnere (10-12 år)
- Vandrere (13-16 år)

i Norges Speiderforbund.

## Kilder til aktivitetene

Aktivitetene er hentet 25.10.2026 fra åpent tilgjengelige aktivitetsbanker og avgrenset til innhold for omtrent 10-15 år (stifinner og vandrer). Hver aktivitet lenker tilbake til originalsiden der du finner full beskrivelse.

## Teknologi

- HTML
- JavaScript (React, innebygd i HTML)

Nettsiden består av én enkelt HTML-fil og krever ingen server, database eller installasjon.

## Hosting

Nettsiden publiseres via GitHub Pages.

## Opphavsrett

Alt innhold og kildekode i dette repositoriet tilhører Simen Nørstebø og Vestbyspeiderne dersom ikke annet er angitt.
Ingen lisens er gitt for gjenbruk, distribusjon eller videreutvikling av kildekoden uten uttrykkelig tillatelse fra opphavspersonen.

Aktivitetene (titler, korte beskrivelser og emneord) tilhører de respektive organisasjonene som er nevnt under «Kilder til aktivitetene». De vises her kun som en søkbar oversikt med lenke til originalsiden, og er ikke omfattet av opphavsretten over.

## Ansvarsfraskrivelse

Dette er et frivillig utviklet hjelpemiddel for bruk i speidergruppen og er ikke et offisielt system fra Norges Speiderforbund, KFUK-KFUM-speiderne, Scouterna eller Det Danske Spejderkorps. Aktivitetene er hentet på ett bestemt tidspunkt og kan være endret eller fjernet hos kilden. Sjekk alltid originalsiden, spesielt for sikkerhet og aldersgrenser.
